# Kaplan Strateji

React + Vite tabanlı, kare haritalı modern koyu temalı RTS strateji savaş oyunu.

## Özellikler

- Kare tabanlı 16x16 savaş haritası
- Oyuncu ve düşman üsleri
- Asker ve tank üretimi
- Altın ve enerji kaynak ekonomisi
- Savunma kulesi inşa noktaları
- Mini harita ve üs can panelleri
- Yapay zekalı düşman üretimi ve saldırısı
- Birlik, kule ve üs can barları
- Patlama efektleri
- Başlat, duraklat ve yeniden başlat kontrolleri

## Komutlar

```bash
npm install
npm run dev
npm run build
```
